# OpenClipper

Self-hosted, open-source AI video clipping: long recordings → short captioned clips, fully local (faster-whisper + Ollama) or with your own API keys, drivable from Claude via MCP.

**Status:** Milestone 0 (discovery & architecture). Nothing runnable yet.
